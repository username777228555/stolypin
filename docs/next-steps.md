# Что дальше

Состояние на 0.18.8: 176 уроков, около 1000 событий, 886 персоналий, 428 памятников культуры, 547 терминов;
пробники 36 олимпиад (`olympiads/`); копия прогресса в Android Auto Backup (`core/autobackup.ts`).

Сделано в 0.18.x для олимпиадников: разобраны финалы «Высшей пробы» 2022–2025, Ломоносова, РАНХиГС, «Изумруда»
и РГГУ (порядок работы — `.agents/skills/add-content/SKILL.md`, «Материалы для олимпиадников»). Закрыты
повторяющиеся типы заданий: вспомогательные исторические дисциплины (термины и урок
`l-muscovy-vspomogatelnye-distsipliny`), мемуары XX века, СССР и «третий мир», отдельные пробелы по заданиям.

Осталось:

1. **Уроки по частым темам олимпиад.** Пробники есть по всем перечневым олимпиадам по истории (36 пакетов, 1120 вопросов;
   без Турнира Ломоносова, олимпиады Вернадского и РГГУ 2024 — в них в основном всеобщая история). Частотный разбор
   (`scripts/qa/olymp_freq.py`, 40 олимпиад-лет 2022–2026) показал темы, которые спрашивают постоянно, а курс раскрывает
   слабо (в скобках — олимпиад-лет из 40 / уроков, где тема раскрыта):
   - денежные реформы от Елены Глинской до деноминации 1998 года (24 / разбросано по 20 урокам, сквозного нет) —
     два урока: до 1917 года и советские и российские реформы; карточки всех реформ в базе есть;
   - Государев двор, Боярская дума, чины и приказы XVI–XVII веков (чины 16 / 1, приказы 7 / 1; «бояре»,
     «окольничий», «волость» не связаны ни с одним уроком);
   - местное управление: губерния и уезд, учреждения 1775 года, городовые положения, земства (7 / 3, «губерния» —
     в 13 олимпиадах);
   - стратегические операции 1943–1945 годов на карте: фронты, командующие, итоги (12 / 1; Крымской и Донбасской
     операций в уроках нет);
   - почётные звания городов и «Золотое кольцо» (9 / 0).
   Уроки пишутся по статьям историков (`LESSONS.md`) — для этого сессии нужен доступ к сайтам источников.
   Финал ВсОШ 2025: второй тур не перенесён — в скачанном PDF только бланк ответов, задания 1–2 по видео.
