# Что дальше

Состояние на 0.19.3: 182 урока, около 1000 событий, 886 персоналий, 428 памятников культуры, 555 терминов;
пробники 36 олимпиад (`olympiads/`); копия прогресса в Android Auto Backup (`core/autobackup.ts`).

Сделано в 0.18.x для олимпиадников: разобраны финалы «Высшей пробы» 2022–2025, Ломоносова, РАНХиГС, «Изумруда»
и РГГУ (порядок работы — `.agents/skills/add-content/SKILL.md`, «Материалы для олимпиадников»). Закрыты
повторяющиеся типы заданий: вспомогательные исторические дисциплины (термины и урок
`l-muscovy-vspomogatelnye-distsipliny`), мемуары XX века, СССР и «третий мир», отдельные пробелы по заданиям.

Сделано в 0.19.x: картинки в вопросах курса и в тексте уроков (`figure`, `lessonFigures`); пробники по всем
перечневым олимпиадам по истории (36 пакетов, 1120 вопросов; без Турнира Ломоносова, олимпиады Вернадского
и РГГУ 2024 — в них в основном всеобщая история). Частотный разбор (`scripts/qa/olymp_freq.py`, 40 олимпиад-лет
2022–2026) выделил темы, которые спрашивают постоянно, а курс раскрывал слабо, — по ним написаны шесть уроков:
денежные реформы до 1917 года (`l-c19-denezhnye-reformy`) и советские и российские (`l-late-ussr-denezhnye-reformy`),
Государев двор, чины и приказы (`l-c17-chiny-i-prikazy`), местное управление от губерний до земств
(`l-c19-mestnoe-upravlenie`), операции 1943–1945 годов (`l-war-operatsii`), почётные звания городов и «Золотое кольцо»
(`l-late-ussr-pochetnye-zvaniya-gorodov`).

Осталось:

1. **Гербы городов.** Олимпиады часто просят сопоставить герб с городом (ВсОШ, «Золотое кольцо», города трудовой
   доблести), а в базе гербов нет. Нужны карточки с картинками гербов и описаниями по источникам (ПСЗ, Винклер,
   Соболева) — сайт ИвГУ со статьёй о гербах Верхнего Поволжья из агента не открылся.
   Финал ВсОШ 2025: второй тур не перенесён — в скачанном PDF только бланк ответов, задания 1–2 по видео.
2. **Quizlet.** Конвейер готов (`scripts/quizlet/README.md`), ждём файл в `import/quizlet/`.
3. **Проверка на телефоне.** Восстановление прогресса после переустановки на реальном устройстве (на эмуляторах
   API 30 и 34 проверено), книга из релиза `books`, зум в Галерее.
4. **Связи `cause`/`part-of`.** Даты проверяет `content:check`; связи с разрывом больше 50 лет просмотрены (0.18.6).
   Осталось выборочно перечитать смысл связей с малым разрывом.
5. **Новые пакеты.** Всемирная история, античность, Китай — отдельными пакетами (`pnpm content:new`).
6. **Уборка.** Ветка `test/autobackup-e2e` на GitHub больше не нужна (удалить из агента не дал прокси).
